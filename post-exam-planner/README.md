# Post-Exam Planner

A premium React prototype for planning your perfect post-exam celebration. Built with React, Vite, and Tailwind CSS.

## Features

- Beautiful, premium concierge-style UI
- Interactive input for describing your plans
- Two-step itinerary display with mock data
- Responsive design that works on all devices
- Smooth animations and transitions
- Pre-populated suggestions for quick testing

## Getting Started

1. Install dependencies:
   ```bash
   npm install
   ```

2. Run the development server:
   ```bash
   npm run dev
   ```

3. Open your browser to the local server URL shown in the terminal

## Usage

Type what you'd like to do (e.g., "Dine out then something fun") and click "Plan My Day" to see your personalized itinerary.

Try these suggestions:
- Dine out then something fun
- Relax and unwind

## Technology Stack

- React 18
- Vite
- Tailwind CSS
- Inter font family
