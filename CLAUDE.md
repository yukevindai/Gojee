# LocalPulse

> Touching grass made simple

## Project Overview

LocalPulse is a post-exam celebration planner that helps users discover and plan local activities. The platform serves as a personal concierge for creating memorable experiences in your city.

## Tech Stack

### Frontend
- **Next.js** - React framework for production
- **Tailwind CSS v4** - Utility-first CSS framework
- **Framer Motion** - Animation library for React

### Backend & Services
- **Supabase** - Authentication and backend services

## Project Structure

## Current Status

The project currently includes a React prototype (`post-exam-planner/`) built with Vite, React, and Tailwind CSS. This serves as the initial UI/UX exploration for the LocalPulse platform.

## Development

The production version will migrate to Next.js with the full tech stack outlined above.
